Secure printing for people who handle confidential documents

Encrypted before it reaches the tray.

Cipherjet seals every print job in authenticated encryption the moment it leaves the application. What waits in the spool is ciphertext — and it becomes a document again only in authorized hands.

Specification

Modern, hard-to-misuse cryptography from libsodium — no invented primitives, nothing you have to configure to be safe.

Cipher
XChaCha20-Poly1305, applied to the job stream in authenticated 64 KiB chunks, so any bit flipped or byte removed is caught before a page ever prints.
Keys
A fresh 256-bit key for every job, wrapped by a master key that is itself protected with the memory-hard Argon2id. One compromise never spreads to another job.
In memory
Key material lives in guarded pages that are locked out of swap and wiped the instant they are no longer needed.
Audit record
Every job is logged in an append-only, hash-chained ledger. Editing or deleting any line breaks the chain, and the break is easy to find.
Platforms
One portable engine across Linux, macOS and Windows. It registers as an ordinary printer, so people simply choose it and press print.
License
MIT. A small, readable codebase with a test suite you can run yourself before you trust it with anything.

A chain of custody, not a spool of plaintext

The path a job takes from an application to paper, with the document sealed for the entire journey in between.

Print

Someone prints as they always would and chooses Cipherjet. The application hands over the job.

Seal

Cipherjet encrypts the job and holds it in the spool as ciphertext. Plaintext is never written to disk.

Release

An authorized operator opens the job and sends it on to the physical printer — the only point it is readable.

Install

Building runs as you; only installing and registering the printer use sudo. Pick whichever fits how you work.

One command

$ curl -fsSL …/securedrv/main/install.sh | bash
Fetches, builds, installs, and registers the printer. Add --no-printer or --uninstall.

From a clone

$ git clone …/securedrv && make printer
make test runs the suite; make install installs the binaries only.

Build dependencies

$ brew install libsodium cmake pkg-config
On Debian: apt install libsodium-dev cmake pkg-config g++.

Prebuilt binaries

$ tar xzf cipherjet-*.tar.gz
Download a build for your platform from Releases.
