Encrypted printing,
end to end.

Cipherjet is a printer driver that encrypts every job the instant it leaves the app and decrypts it only at release. Plaintext never touches disk.

Get started Download binaries
install — bash
$ curl -fsSL https://raw.githubusercontent.com/Eselase-Noble/securedrv/main/install.sh | bash

Builds, installs, and registers “Cipherjet (Encrypted)” as a printer.

Why Cipherjet

Security you don't have to think about

Modern authenticated cryptography via libsodium, wrapped in a driver your users never notice.

🧬

Envelope encryption

A fresh 256-bit key per job, wrapped by an Argon2id-protected master key. Jobs are cryptographically isolated.

🌊

Streaming AEAD

XChaCha20-Poly1305 in authenticated 64 KiB chunks — any size job, and every bit-flip or truncation is caught.

📜

Tamper-evident audit

A BLAKE2b hash-chained, append-only log. Editing or deleting any entry breaks the chain and is detected.

🖨️

Appears as a printer

Registers with CUPS so staff just press ⌘P and pick “Cipherjet (Encrypted).” Release is admin-only.

🧩

Cross-platform

One portable C++17 engine on Linux, macOS and Windows; OS specifics isolated to a single file.

⚖️

Open source

MIT licensed, dependency-light, and covered by a self-contained test suite. Read every line.

How it works

Capture → spool → release

01

Print

The app sends the job to the Cipherjet driver.

→
02

Encrypted spool

The job is encrypted and stored as ciphertext — never plaintext.

→
03

Admin release

A trusted operator decrypts and sends it to the real printer.

Install

Up and running in one command

Building runs as you; only installation and printer registration use sudo.

One command

curl -fsSL https://raw.githubusercontent.com/Eselase-Noble/securedrv/main/install.sh | bash
Add --no-printer for binaries only, or --uninstall to remove.

From a clone

git clone https://github.com/Eselase-Noble/securedrv.git cd securedrv && make && make printer
make test runs the suite · make install installs binaries only.

Homebrew deps (macOS)

brew install libsodium cmake pkg-config
Then build with make. Debian: apt install libsodium-dev cmake pkg-config g++.

Prebuilt binaries

tar xzf cipherjet-*.tar.gz sudo ./install/install-cups-printer.sh
Grab a tarball from Releases.
Guarantees

What the crypto buys you

  • ✓ Confidentiality at rest — steal the spool and you get ciphertext.
  • ✓ Integrity — a tampered job fails release and is preserved for review.
  • ✓ Keys guarded in memory — locked out of swap and wiped on free.
  • ✓ Metadata authenticity — title/time bound to the payload.
  • ✓ Per-job key isolation — one compromise never spreads.
  • ✓ Auditable — hash-chained log proves what happened.
